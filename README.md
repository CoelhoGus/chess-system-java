# ♟️ Chess System in Java

A chess system developed in Java as part of my studies in Object-Oriented Programming.

## 📖 About the Project

This project consists of a complete chess system developed in Java, with a focus on applying Object-Oriented Programming concepts in a practical project.

The system is developed step by step, starting with the basic structure of the chess board and pieces and progressively implementing the rules and mechanics of a chess game.

## 🎯 Project Goals

The main goal of this project is to apply and reinforce Java and Object-Oriented Programming concepts through the development of a complete chess system.

Throughout the project, concepts such as:

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition
- Enumerations
- Exception handling
- Method overloading and overriding
- Collections
- Matrix data structures
- Layered architecture
